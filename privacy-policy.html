Política de Privacidad

La Carpeta del Docente Offline
Última actualización: 10 de septiembre de 2026

Resumen: esta edición está diseñada para funcionar localmente. No requiere crear una cuenta ni sincroniza automáticamente la información académica con estudiantes, directivos o las demás aplicaciones del ecosistema.

1. Alcance

Esta Política de Privacidad explica cómo se maneja la información al utilizar La Carpeta del Docente Offline, una aplicación Android destinada a apoyar la organización académica de docentes.

2. Información que puede registrar el usuario

La aplicación puede almacenar información introducida por el docente, incluyendo nombre de grupos, nombres de alumnos, fechas de nacimiento, asistencia, calificaciones, evaluaciones, rúbricas, actividades, planeaciones, notas, eventos, archivos importados y reportes generados. Esta información se utiliza para proporcionar las funciones solicitadas por el propio usuario.

3. Almacenamiento local

La información académica de la edición Offline se guarda localmente en el dispositivo y/o en archivos que el usuario decide crear, importar, exportar o respaldar. La aplicación no requiere un servicio de cuenta en línea para funcionar.

4. Recopilación y transmisión

La edición Offline no está diseñada para transmitir automáticamente al desarrollador la información académica registrada por el usuario. Tampoco sincroniza automáticamente datos con El Cuaderno del Estudiante, El Escritorio del Director ni con la versión conectada de La Carpeta del Docente.

5. Venta y uso publicitario de datos

La aplicación Offline no vende información académica de los usuarios ni utiliza esa información para publicidad personalizada.

6. Archivos, exportaciones y respaldos

El usuario puede seleccionar documentos, generar reportes o crear respaldos. Si decide copiar, compartir o almacenar esos archivos mediante otra aplicación, servicio en la nube, correo electrónico o sistema de almacenamiento externo, el tratamiento posterior quedará sujeto a las condiciones y políticas del servicio elegido por el usuario.

7. Calendario y notificaciones

Cuando el usuario lo autoriza, la aplicación puede acceder al calendario del dispositivo para crear eventos relacionados con actividades académicas. También puede utilizar notificaciones para mostrar recordatorios, eventos del día y cumpleaños registrados. Estos permisos se utilizan únicamente para funciones solicitadas dentro de la aplicación.

8. Reconocimiento de texto y análisis local

La aplicación puede analizar documentos e imágenes compatibles para detectar fechas y clasificar actividades académicas. El procesamiento está diseñado para realizarse en el dispositivo mediante componentes incluidos en la aplicación. El usuario debe revisar la información detectada antes de incorporarla a su planeación.

9. Datos de menores de edad

La aplicación está dirigida a docentes y no está diseñada como una aplicación infantil. El docente puede registrar información de alumnos, incluidos menores de edad, en el contexto de sus actividades profesionales. El usuario es responsable de contar con la autorización y base legal que corresponda y de cumplir con las políticas de su institución y con la legislación aplicable.

10. Permisos

La aplicación puede solicitar permisos para notificaciones, calendario y autenticación biométrica cuando una función lo requiera. Para seleccionar o crear archivos se emplean mecanismos del sistema Android siempre que sea posible. El usuario puede administrar o revocar permisos desde la configuración de Android.

11. Seguridad

Se aplican medidas razonables orientadas a limitar el acceso no autorizado dentro del alcance de una aplicación local. No obstante, ningún sistema es completamente infalible. El usuario debe proteger su dispositivo, mantener un bloqueo de pantalla adecuado y conservar sus respaldos en ubicaciones seguras.

12. Conservación y eliminación

La información local se conserva mientras permanezca almacenada en el dispositivo o en los respaldos creados por el usuario. El usuario puede eliminar registros desde la aplicación, borrar los archivos generados o desinstalar la aplicación. La desinstalación puede eliminar datos internos de la app, salvo copias o respaldos que el usuario haya guardado fuera de ella.

13. Servicios de terceros

Esta política corresponde a la edición Offline. Algunas bibliotecas técnicas incluidas pueden formar parte del funcionamiento de Android, visualización de documentos, reconocimiento de texto u otras funciones internas. La edición Offline no utiliza dichas funciones para crear un sistema de sincronización académica con terceros.

14. Cambios futuros

Las futuras aplicaciones conectadas del ecosistema tendrán su propia información de privacidad y podrán requerir términos adicionales antes de habilitar sincronización en línea. Esta política será actualizada si cambian las prácticas de la edición Offline.

15. Contacto

Para cuestiones de privacidad o soporte, el usuario puede utilizar el medio de contacto publicado en la ficha oficial de Google Play o la página de Soporte de este sitio.

16. Vigencia

Esta política entra en vigor en la fecha indicada al inicio y se mantendrá disponible públicamente en este sitio.
